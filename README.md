# AtomicMail.io Account Generator

Генератор аккаунтов для [atomicmail.io](https://atomicmail.io) — приватного почтового сервиса.

Режим **полуавтомат**: скрипт заполняет форму регистрации, пользователь решает CAPTCHA вручную.

## Возможности

- 🔄 Массовая генерация аккаунтов в одном цикле
- 🔐 Один пароль для всех аккаунтов (или авто-генерация)
- 💾 Сохранение в формате `mail:pass`
- 🔑 Сохранение seed-фраз для восстановления аккаунтов
- 🧹 Автоматическая очистка кук и сессии между аккаунтами

## Установка

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Установить браузер Playwright
playwright install chromium
```

## Использование

```bash
# 10 аккаунтов с указанным паролем
python main.py -n 10 -p "MyStr0ng!Pass"

# 5 аккаунтов, пароль генерируется автоматически
python main.py -n 5

# Свой файл вывода
python main.py -n 20 -p "MyPass123!" -o my_accounts.txt -s my_seeds.txt
```

### Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `-n, --count` | Количество аккаунтов (обязательно) | — |
| `-p, --password` | Пароль для всех аккаунтов | авто-генерация |
| `-o, --output` | Файл для `mail:pass` | `accounts.txt` |
| `-s, --seeds` | Файл для seed-фраз | `seeds.txt` |

## Как это работает

1. Открывается видимое окно браузера
2. Скрипт заполняет: имя → юзернейм → пароль
3. Извлекает и сохраняет seed-фразу (12 слов)
4. Появляется CAPTCHA — **решаете вручную**
5. После решения (`/app/auth/welcome`) аккаунт сохраняется
6. Куки и сессия очищаются → следующий аккаунт

## Формат вывода

**accounts.txt:**
```
username1@atomicmail.io:MyStr0ng!Pass
username2@atomicmail.io:MyStr0ng!Pass
```

**seeds.txt:**
```
username1@atomicmail.io:word1 word2 word3 ... word12
```
